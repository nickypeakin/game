# Libraries

Copies of the two libraries the game uses, served from this site so a network
that blocks public CDNs (common on school Chromebooks) can't break the game.

| File | Library | Version | License |
| --- | --- | --- | --- |
| `three.min.js` | [Three.js](https://threejs.org/) | r128 (npm `three@0.128.0`) | MIT |
| `peerjs.min.js` | [PeerJS](https://peerjs.com/) | 1.5.4 (npm `peerjs@1.5.4`) | MIT |
